# Персональные приглашения MANGUST

1. Сначала выполните `supabase/05_INVITATIONS.sql` в Supabase SQL Editor. **Не запускайте заново 01_FULL_SETUP.sql** для этого обновления.
2. Загрузите на GitHub Pages файлы из архива, сохранив папки. `js/config.js` остаётся существующим (не включён в обновление).
3. Войдите в `admin.html`, создайте приглашение по ФИО и местам, например `ПАРТЕР, -2, 17`. Места сразу занимают позиции в `reserved_seats`.
4. Скопируйте ссылку **сразу после создания**: в базе хранится только SHA-256 хеш токена, повторное получение ссылки невозможно.
5. Гость подтверждает или отказывается. При отказе места автоматически освобождаются.
6. Для проверки обновите список бронирований в админ-панели.

**Важно:** SQL не выполнен автоматически, без него функции не заработают. На существующем Supabase и GitHub Pages изменения не развернуты и не протестированы. Приглашения пока создаются по ручному вводу мест (не кликом по схеме). В базе у приглашения служебные значения телефона/email, не используйте их для связи. Токен — секрет, не публикуйте ссылку в открытом доступе.
